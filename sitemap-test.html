Troubleshooting Notes:

If the sitemap doesn't display properly, check the following:

  • Ensure both sitemap.xml and sitemap.xsl files are in the same directory
  • Verify the server is serving the files with the correct MIME types
  • Check browser console for any errors
  • Try viewing in different browsers (Chrome, Firefox, Safari, etc.)

MIME Types Required:

text/xml or application/xml for sitemap.xml
text/xsl or application/xslt+xml for sitemap.xsl
